# Motricidade × Dependência — MD 2036

Ferramenta pedagógica para análise estrutural dos eventos prospectivos da Pesquisa MD 2036.

## Recursos

- gráfico Motricidade × Dependência;
- quadrantes interpretativos;
- matriz editável de influência entre eventos;
- classificação automática dos eventos;
- exportação em JSON e CSV.

## Escala

- 0 = não influencia;
- 1 = influência fraca;
- 2 = influência média;
- 3 = influência forte.

## Publicação

Crie um repositório chamado `Motricidade` e envie os arquivos na raiz. Depois ative o GitHub Pages em `Settings → Pages → Deploy from a branch → main → /root`.
